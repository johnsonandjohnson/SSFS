# About
Collection of R utility functions  to generate the simulation results as described in ‘Powering up: enhancing success rates in biomarker discovery & reproducibility: Sample Size Calculation for Feature Selection’.

# Requirements

* R (tested on R >= 4.2.0)


# Usage

* Create an "Illustration" directory in the project root.
* Copy the scripts NewMethod.R and SimFunctions.R into Illustration directory.
* See supplementary material 1 in ‘Powering up: enhancing success rates in biomarker discovery & reproducibility: Sample Size Calculation for Feature Selection’
